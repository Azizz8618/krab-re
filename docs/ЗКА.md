# Загрузка документа в КРАБ с перфоленты (колода ЗКА)

Проверено на живой машине 18.10.2026. Готовый сценарий подачи —
`~/Yandex.Disk/simh/BESM6/UVU/krab.input.ini`.

## Колода

Исходная колода — `VVOD/vkrab.txt` (2301 строка), шапка:

```
шифр 410300 зка^
ЕЕВ1А3
*NAME
ГЕН	СТАРТ	'70000'
...
ФИНИШ
ЕКОНЕЦ
```

То есть шапка — паспорт задачи (шифр 410300, номер стандартного паспорта
`ЗКА`) и программа загрузки; `ФИНИШ` — конец программы, `ЕКОНЕЦ` — конец
колоды. Документ читается с того же устройства ввода, поэтому текст
вставляется **между `ФИНИШ` и `ЕКОНЕЦ`**.

## Подача колоды

Сценарий `UVU/krab.input.ini` подключает колоду к считывателю перфоленты и
подает сигнал FS8:

```
detach fs0
at -t fs0 ~/Yandex.Disk/simh/BESM6/VVOD/vkrab.txt
d 6 1
d 5 10
set cpu req
go
```

Чтение происходит медленно (карты идут с ограничителем скорости), и ОС
отвечает на промахи **замятием ввода `ЗМЛ0`** — периодическая ошибка,
возникает и на реальной машине, в эмуляторе чаще. Повторы сигнала FS8 должны
идеть с паузами в десятки секунд.

## Что отвечает эта установка ОС

Паспорт из шаблона **не проходит**:

```
ОШЛ0 410300000000  АВВД   НПК НСТ НС СИМ  ШИФР  410300000000
00000  0001 02 06 115  З ШИФР
00000  0001 02 07 045  Ч ЛИСТ
00000  0001 02 07 045  ВРЕМЯ
```

Расшифровка по руководству пользователя ОС ДИСПАК
(`re-dispak/docs/Dispak-programmer-guide.md`):

| Признак | Значение |
| --- | --- |
| `З ШИФР` | запрещённый шифр: пользователя с таким шифром нет в списках ОС, **либо заказ/отмена стандартного паспорта сделана неверно** — то есть номера `ЗКА` в этой установке нет |
| `Ч ЛИСТ` | не задан раздел «ВХОД» паспорта (адрес входа) |

Та же ошибка выдаётся и на **не изменённой** колоде — подтверждено.

Замена шапки на зарегистрированный номер (`шифр 123400 зс5^`) и явный
`ВХОД 70000^` дают другую картину: ОС отвечает замятием `ЗMB0` (то же
периодическое замятие ввода), после повторов с паузами колода уходит на
чтение.

Признаки, по которым видно, что задача дошла: отчёт `ОШЛ0 <шифр>` со списком
ошибок паспорта (например `З ШИФР`, `Ч ЛИСТ`), а в конце — строка
`KЗ(002) <шифр> <время>`, означающая завершение задачи.

## Что нужно выяснить

- какая форма шифра нужна паспорту: `410300 зка` (номер стандартного
  паспорта) на этой установке не проходит (`З ШИФР`), а `123400 зс5`
  проходит с замятием;
- какие параметры ждет программа ЗКА после чтения колоды.

## Автотест

`tests/test_vvod_zka.py` строит колоду из `VVOD/vkrab.txt` (шапка заменяется
на `шифр 123400 зс5^` + `ВХОД 70000^`, документ — между `ФИНИШ` и `ЕКОНЕЦ`),
подает её по сценарию выше с повторами при замятии, затем проверяет в КРАБ:
директива `СБО` должна показать файл, которого не было до ввода.
