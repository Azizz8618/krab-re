# ЗКА — загрузка массивов в КРАБ с перфокарт и перфоленты

Разбор по первоисточникам: колода `~/Yandex.Disk/simh/BESM6/VVOD/vkrab.txt`
(2301 строка, автокод БЕМШ), таблица паспорта массива в модуле КРАБ `F13`
(`texts/F13`, блок `ПЧ`), описания ввода задач ОС ДИСПАК
(`re-dispak/docs/Dispak-operator-guide.md`, `simh/BESM6/docs/ВВОД_АНАЛИЗ.md`).

## Что такое ЗКА

**ЗКА — служебная задача ОС ДИСПАК с шифром `410300`**, программа на автокоде
БЕМШ, работающая через библиотеку **СИПРОД** (`СИПР3`/`СИПР4`). Она читает
входную колоду (перфокарты или перфолента) и загружает массивы в архив КРАБ.

Паспорт задачи в колоде — обычный паспорт ОС ДИСПАК, первая строка которого
и даёт название «ЗКА»:

```
шифр 410300 зка^
ЕЕВ1А3
*NAME
ГЕН	СТАРТ	'70000'
...
	ФИНИШ
ЕКОНЕЦ
```

Тот же шифр `410300` встречается в других колодах того же каталога: например
`VVOD/vvod_dubna.txt` — «ШИФР 410300 / ОЗУ 32 / ТЕЛЕ^ / tap 60(2148) /
дис 57(2048) / АЦП 128 / ВХО 1 / ВРЕ 1 / ЕВ1».

## Команды входной колоды

Программа не просто копирует данные: она разбирает **командный язык колоды**.
В `vkrab.txt` есть таблица команд с адресами обработчиков:

| Команда | Обработчик | Команда | Обработчик |
| --- | --- | --- | --- |
| `КАТ` | `G70015` | `ЗАХ` | `G71506` |
| `ЭВМ` | `G71045` | `РЕС` | `G71145` |
| `ШИФ` | `G71240` | `СУБ` | `G70756` |
| `ДЛИ` | `G71214` | `ОТЛ` | `G71615` |
| `УСТ` | `G71534` | `ТРА` | `G71642` |
| `УПР` | `G70773` | `БОШ` | `G71711` |
| `КТЧ` | `G71346` | `ЗАП` | `G72174` |
| `БАЦ` | `G71015` | `ВЫД` | `G71737` |
| `ВЫТ` | `G71423` | `КОН` | возврат |

Разбор — по первым символам записи: слово сравнивается с таблицей
(`сч D70652+17(М16) / нтж БУФЕР / и E48П25`), при совпадении управление
уходит по адресу из пары. Неизвестная команда — диагностика
`НЕТ ТАКОГО ПАРАМЕТРА`.

Строки-параметры в колоде набираются как `ПАРАМЕТР…` (в тексте программы
`ТПАРАМ конд п'ПАРАМЕ'`), а вопрос генерации — `ПОЛНАЯ ГЕНЕРАЦИЯ (ДА/НЕТ)`.

## Что программа делает с массивами

Основной цикл (метки `G70015`, `G70024`, `G70040`, `G70073`) построен на
вызовах библиотеки СИПРОД:

- чтение записи: `БУФЕР` + `INP` (и `INPSEK` — по секциям);
- разбор полей: сравнение с ключом `КЛЮЧ` и выделение по маске `MACKAЗ`;
- выбор носителя: `ДАЙМД` («дать МД») — по параметрам массива определяется
  диск/архив;
- запись: `ЗАПОСВ` (запись с сопровождением) и `ЗАПИСЬ`;
- дублирование: `ДДУБ` («дать дубль») и таблица `ТДУБЛИ` — массив пишется и
  на дублирующий носитель;
- обмен и служебное: `ОБМЕН`, `ОБМАН`, `ТАБЛИС`, `КЛЮЧ`, `ДЛИ`, `ОСВЛИС`.

Дублирование видно прямо в тексте: обработчик `G70035` копирует слово
`D72765` в `D72766` и вызывает `ТДУБЛИ`, после чего `ДАЙМД` запрашивается
дважды — для основного и для дублирующего носителя.

## Паспорт массива (модуль `F13`, блок `ПЧ`)

Массивы печатаются и перфорируются вместе с паспортом — это и есть формат,
который читает ЗКА. В `texts/F13` он собран как последовательность констант
карты:

```
ПЧ:      'ШИФР  ' <шифр> '/' <пшифр> '0ЛИСТ ' '0-3,34' '-370  '
         '0ПОВТ0' '0РОС 0' '0ЛЕН 3' '5(0000' ')0ВХО ' '41000 ' 'Е'
```

Поля, по именам из того же блока: `ПЧШИФ`/`ПЧПШИФ` (шифр и пароль), `ПЧАЦП`,
`ПЧВРЕ`, `ПЧБОБ`, `ПЧУСТР` (устройство вывода: 0 — АЦПУ, 1 — ПК, 2 — ПЛ),
`ТИПП` (тип вывода: `ПН`/`ПБ`/`РН`/`РБ`/`ЛН`/`ЛБ`, для перфорации —
`УПП`/`ЕС`/`СDС`/`УПДК`), `ПЧСТР` (строк в листе), `ПЧКОНТ` (контекст),
`ПЧХОЗ` (хозяин), `ПЧАРХ` (номер архива), `ПЧБДД`, `ПЧСДВ`.

То есть в колоде перед данными массива идёт карта-паспорт, начинающаяся со
слова `ШИФР`; по ней ЗКА определяет, куда и под каким хозяином класть
массив, сколько в нём зон и нужно ли дублирование.

## Как это запускают

Задача вводится как обычная задача ОС ДИСПАК — колода на устройстве ввода
(перфокарты `vu0`, перфолента/фотосчитыватель `fs0`). Порядок для этой
машины описан в `simh/BESM6/docs/ВВОД_АНАЛИЗ.md`:

```
detach vu0
at vu0 /абсолютный/путь/к/колоде.txt
d 6 1
d 5 10
set cpu req
go
```

Признак приёма — `B075-1 ШИФР` в очереди (`НОМ` на операторском терминале),
завершение — `КЗ(075) ШИФР`. Вывод задачи идёт на АЦПУ (файл
`ACPU/output.txt`), который должен быть подключён оператором (`ДАЙ А0`).

## Что осталось выяснить

- полный список параметров каждой команды (`КАТ`, `ЭВМ`, `ШИФ`, `ДЛИ`,
  `УСТ`, `УПР`, `КТЧ`, `БАЦ`, `ВЫТ`, `ЗАХ`, `РЕС`, `СУБ`, `ОТЛ`, `ТРА`,
  `БОШ`, `ЗАП`, `ВЫД`) — по обработчикам `G7xxxx` в `vkrab.txt`;
- точное соответствие полей паспорта массива (`F13`, блок `ПЧ`) позициям
  карты: часть полей собрана из констант с разделителями;
- формат колоды на перфоленте: у ЗКА есть ветки `ВВОДШ`/`ВВОД8`/`ВВОД10`
  и `INPSEK` — по ним видно, что записи читаются секциями.
