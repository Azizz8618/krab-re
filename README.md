# КРАБ — диалоговый комплекс программ СКП ЭВМ МГУ

Исходные тексты диалоговой системы **КРАБ** (Комплекс программ для Работы
Абонентов) — базовой системы дистанционного доступа СКП ЭВМ МГУ, работавшей
под управлением **ОС ДИСПАК** на **ЭВМ БЭСМ-6**.

Система разработана на факультете ВМК МГУ в 1977—1978 гг. и эксплуатировалась
с октября 1978 года. Обслуживала до 24 одновременных пользователей в режиме
разделения времени, регистрировала свыше 2000 абонентов.

## Что в репозитории

| Каталог | Содержимое |
| --- | --- |
| `original/` | 176 оригинальных модулей в 8-разрядной кодировке ОС ДИСПАК (как в архиве) |
| `texts/` | Те же 176 модулей, декодированные в UTF-8 |
| `docs/` | Инвентаризация модулей, заметки о кодировке, все форматы директивы `ФОР` ([`docs/FOR.md`](docs/FOR.md)) |
| `tools/` | Декодер и генератор инвентаризации |
| `tests/` | Живые тесты КРАБ на эмулируемой БЭСМ-6: доступ в номер, директивы, редактирование, ФОР + ЛИСТ — см. [«Живые тесты системы»](#живые-тесты-системы) |
| `AGENTS.md` | Сводное описание архитектуры, директив и диагностик системы |

Оригинальный архив `тексты КРАБа.zip` (590 КБ) сохранён в корне репозитория
для сверки целостности.

## Состав системы

Система строилась из взаимодействующих программ, работавших в мультипрограммном
режиме под ОС ДИСПАК:

- **Монитор абонентов** — ядро системы, обслуживающее терминалы: диспетчер
  терминалов, редактор, архивная служба, блок формирования задач, диспетчер
  подчинённых задач, бюджетно-статистическая служба;
- **Программа Лист** — просмотр листинга задачи на экране дисплея;
- **Подсистема Сервис** — перепись файлов между архивом и библиотеками;
- **Бюджетно-статистическая подсистема (БСС)** — распределение бюджета
  и сбор статистики;
- **Автономный и системный формирователи** — формирование задач и перенос
  их на буфер ввода ОС ДИСПАК;
- **Программа ПК** — вывод файлов на АЦПУ, перфокарты и перфоленту;
- **Программа Генератор** — задание конфигурации системы;
- **Служебные программы (СЛЗАД)** — дублирование архива, распечатка каталогов;
- **Школа** — встроенная система обучения, отвечавшая на `ШКО <ДИРЕКТИВА>`.

Помимо этого, в корпусе присутствуют модули сети ЭВМ **НЕРПА** — драйверы
связи БЭСМ-6 ↔ МАМС и файловый протокол, а также полный текст докторской
диссертации Н. В. Макарова-Землянского «Архитектура и программная реализация
сети ЭВМ НЕРПА».

Подробнее о каждом файле — в [`docs/INVENTORY.md`](docs/INVENTORY.md).

## Кодировка ОС ДИСПАК

Файлы в `original/` хранятся в 8-разрядной кодировке ОС ДИСПАК. Кириллица в
ней размещена так:

| Диапазон | Назначение |
| --- | --- |
| `0x80`–`0x9F` | прописные `А…Я` (32 знака, `Ё` отсутствует) |
| `0xA0`–`0xAF` | строчные `а…п` (первые 16) |
| `0xB0`–`0xDF` | резерв, в текстах практически не встречается |
| `0xE0`–`0xEF` | строчные `р…я` (последние 16) |
| `0xF0`–`0xFE` | резерв |
| `0xFF` | `Ё` (единичные случаи) |
| `0x20`–`0x7F` | латиница и знаки ASCII, включая рамку из `*`, `-`, `=` |

Разрыв строчного регистра между `0xAF` и `0xE0` — особенность именно кодовой
таблицы ОС ДИСПАК, а не повреждение файла. Ни КОИ-8, ни CP866, ни ISO-8859-5
эти файлы не читают корректно.

Подробности и проверочные примеры — в [`docs/ENCODING.md`](docs/ENCODING.md).

## Инструменты

Декодирование корпуса в UTF-8:

```bash
python3 tools/decode.py original -d texts
```

Декодирование одного файла в stdout:

```bash
python3 tools/decode.py original/BUD0
```

Проверка без записи (пакетный режим, `--check`):

```bash
python3 tools/decode.py original -d texts --check
```

Перегенерация инвентаризации модулей:

```bash
python3 tools/inventory.py original -o docs/INVENTORY.md
```

Освобождение сбойных зон номера (без прав администратора):

```bash
python3 tools/clear_sbo.py --list     # только показать, что занято
python3 tools/clear_sbo.py            # освободить
```

Работает по описанию `ИМЯ` из Школы: пара вызовов `ИМЯ <файл>` поднимает
файл с сбойных зон и тут же уничтожает его как текущий. Подробнее —
[`docs/EDITING.md`](docs/EDITING.md).

Скрипты написаны на чистом Python 3 без внешних зависимостей.

## Живые тесты системы

В каталоге `tests/` лежат тесты, которые проверяют КРАБ на работающей
машине: доступ в номер абонента, директивы Монитора, редактирование
текстов, формирование задач и просмотр листинга программой ЛИСТ.

### Требования

| Компонент | Назначение | Примечание |
| --- | --- | --- |
| SIMH БЭСМ-6 + конфигурация ОС ДИСПАК | машина с системой КРАБ | нужны диски КРАБ: архив и ленты |
| Эмулятор терминала 15ИЭ-00-013 | терминал 15ИЭ для диалога | путь задаётся `IE15_HOME` |
| Python 3 + pytest | запуск тестов | других зависимостей нет |

Проверено с SIMH в режиме `set throttle=1m`: счёт на эмулируемой БЭСМ-6 идёт
медленно, поэтому формирование задачи и загрузка программы ЛИСТ занимают
десятки секунд.

### Переменные окружения

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `IE15_HOME` | `~/Yandex.Disk/ie15` | каталог эмулятора терминала |
| `KRAB_PORT` | `4202-4223` | линии ДКС; занятые пропускаются автоматически |
| `KRAB_LIVE_FORM` | — | `1` — включить длительный прогон формирования |

### Запуск

Все наборы — каждый в своём процессе:

```bash
sh tests/run_all.sh
```

Отдельный набор:

```bash
cd tests && python3 -m pytest test_krab_task_list.py -v
```

### Состав наборов

| Набор | Тестов | Что проверяет |
| --- | --- | --- |
| `test_krab_entry.py` | 7 | баннер КРАБ, протокол входа `НАЧ → КТО? → КЛЮЧ-`, выход `КОН`, отказы (неверный ключ, чужой номер) |
| `test_krab_directives.py` | 12 | `ТЕР`, `ВРЕ`, `КТО`, `КЛ`, `ДЛИ`, `СОС`, `ЧТО`, `ГДЕ`, блок `ШКО`, повторный вход |
| `test_krab_edit_form.py` | 10 | `ИМЯ`, `ДОП`, `ВЫД`, `УПЛ`, `РЕД`, `ЗАП`, `ФОР` |
| `test_krab_task_list.py` | 7 | архив номера 1234 (Фортран `ФОРГДР`, Паскаль `КАЛЬК` с `ТЕЛЕ^` в паспорте), `ФОР ПЗ` → `ЛИС` → `ДЛИ`/`ВЫД` |

Тесты работают под номером **1234** с ключом **1234** — его файлы лежат в
общем архиве системы, поэтому ничего дополнительно готовить не нужно.

Если требуется запуск нескольких задач, шифры назначаются **подчинёнными**
номеру: `123401`, `123402`, `123403` и далее. Так их видно в каталоге
ввода ОС Диспак и в выдаче `КТО`, и они не путаются с задачами других
пользователей. У номера может быть только одна подчинённая задача, поэтому
перед формированием очередной ПЗ предыдущую нужно дождаться или сбросить
директивой `ВЫБ`.

### Особенности протокола, учтённые в тестах

Сняты с живой машины (версия 19 от 27.11.92):

- формировать задачу для просмотра можно только **подчинённой**: `ФОР ПЗ`
  для обычной программы, `ФОР ПС` — для диалоговой (паспорт с `ТЕЛЕ^`);
- `ФОР ПЗ` включает подсистему и спрашивает `ПОДСИСТЕМА ВКЛЮЧЕНА /
  ВОЙТИ? (ДА,НЕТ)` — нужен ответ `ДА`;
- у номера может быть **одна** подчинённая задача: при занятой ПЗ `ФОР ПЗ`
  отвечает `УЖЕ ЕСТЬ ПЗ`, а `ЛИС` — `НЕТ ПЗ В РЕШЕНИИ`;
- `ЛИС` переводит терминал в отдельную программу со своим приглашением `*`
  и возвращает в Монитор по `КОН`;
- ожидание ответа — по приглашению в конце кадра (`-`, `*`, `+`, `/`),
  а не по паузе: директивы вроде `КТЛ` печатают каталог на десятки строк.

Сравнения учитывают особенность набора Н2 терминала: часть кириллицы
выводится латинскими двойниками (`PASCAL` ← `РАSСАL`, `FTN` ← `FТN`).

### Замечания по надёжности

Все наборы работают под одним номером и одной машиной, поэтому запускать их
одновременно нельзя. Каждый набор в своём процессе — не формальность:
в одном процессе классы делят номер 1234 и линии ДКС, состояние протекло бы
между наборами. Это же делает прогоны независимыми от зависших линий:
при сбое входа драйвер переподключается на другую свободную линию ДКС.

## Формат модуля

Каждый текст — паспорт ОС ДИСПАК, за которым следует тело модуля. Шапка
выглядит так:

```
ШИФР 991800 ЗСМ
ИМЯ ЗПБЮД0
ЛИС 0-37
ВРЕ 240
ТРА 35
ЛЕНТ 42(2086-ЗП)
```

где `ШИФР` — шифр задачи, `ИМЯ` — внутреннее имя модуля, `ЛИС` — диапазон
зон листинга, `ВРЕ` — лимит процессорного времени, `ТРА` — транспортный
параметр, `ЛЕНТ` — номера лент с библиотеками.

Далее чаще всего идёт рамочный заголовок вида

```
**********************************************
*                                            *
*    Д И А Л О Г О В А Я    С И С Т Е М А    *
*                К  Р  А  Б                  *
*                                            *
```

с указанием подсистемы и части, а затем тело на языке БЭСМ-6.
